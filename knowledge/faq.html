Frequently Asked Questions (FAQ)

General Questions

1. What is Payment Portal?

Payment Portal is a sample Kubernetes application used for learning Docker, Kubernetes, Amazon Bedrock, Generative AI, and Retrieval Augmented Generation (RAG).

2. Which web server is used?

The application is hosted using the NGINX web server.

3. Which platform hosts this application?

The application runs inside a Kubernetes cluster.

Kubernetes Questions

4. How many Pods are running?

Run the following command: 

kubectl get pods

5. How do I list all Deployments?

kubectl get deployments

6. How do I check all Services?

kubectl get services

7. How do I view application logs?

kubectl logs POD_NAME

8. How do I describe a Pod?

kubectl describe pod POD_NAME

9. How do I restart a Deployment?

kubectl rollout restart deployment payment-portal

Restarting a Deployment performs a rolling restart of its Pods without changing the Deployment specification. :contentReference[oaicite:0]{index=0}

10. How do I scale the application?

kubectl scale deployment payment-portal --replicas=3

Troubleshooting

11. What should I do if the Pod is in CrashLoopBackOff?

Check:

  • Application logs
  • Container configuration
  • Secrets
  • ConfigMaps
  • Environment variables

12. What causes ImagePullBackOff?

Possible reasons include:

  • Incorrect image name
  • Wrong image tag
  • Private registry authentication failure
  • Image does not exist

13. Why is my Pod in Pending state?

Common reasons include:

  • Insufficient CPU
  • Insufficient Memory
  • Node scheduling constraints
  • Persistent Volume not available
Pods remain in the Pending phase until Kubernetes can successfully schedule them to a node and start their containers. :contentReference[oaicite:1]{index=1}

14. Why is my Service not accessible?

Verify:

  • Service selector
  • Target Port
  • Pod labels
  • Running Pods
  • Application listening port
Debugging a Service usually involves checking selectors, endpoints, ports, and connectivity to the backing Pods. :contentReference[oaicite:2]{index=2}

Operations

15. How do I execute commands inside a Pod?

kubectl exec -it POD_NAME -- /bin/sh

16. How do I list all Kubernetes resources?

kubectl get all

17. How do I check rollout status?

kubectl rollout status deployment payment-portal

18. How do I rollback a Deployment?

kubectl rollout undo deployment payment-portal
Kubernetes Deployments support rollout status, restart, history, and rollback operations through the `kubectl rollout` command family. :contentReference[oaicite:3]{index=3}
