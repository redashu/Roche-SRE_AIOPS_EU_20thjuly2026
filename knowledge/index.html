Payment Portal

Welcome to the Payment Portal documentation website. This application is deployed on a Kubernetes cluster and is used for training, demonstrations, and AI-powered troubleshooting.

Application Overview

Payment Portal is a web-based application that allows customers to securely process online payments. The application is containerized using Docker and deployed on Kubernetes using a Deployment and Service.

The application follows cloud-native design principles and is designed for high availability, scalability, and easy deployment.

Technology Stack

  • HTML 5
  • NGINX Web Server
  • Docker
  • Kubernetes
  • NodePort Service
