About Payment Portal

Payment Portal is a cloud-native web application developed for demonstrating modern application deployment on Kubernetes. The application is intentionally simple so that engineers can focus on Kubernetes, DevOps, Cloud Computing, Generative AI, and Retrieval Augmented Generation (RAG) concepts rather than complex business logic.

Business Overview

Payment Portal simulates an online payment processing application where customers can securely submit payment requests through a web interface. Although this training version does not perform real financial transactions, its architecture closely resembles enterprise web applications deployed in production environments.

Application Goals

  • Demonstrate containerized application deployment.
  • Understand Kubernetes Deployment and Service objects.
  • Learn application scaling and rolling updates.
  • Generate realistic operational data for AI demonstrations.
  • Create documentation for Retrieval Augmented Generation (RAG).
  • Demonstrate AI-assisted Kubernetes troubleshooting.

Key Features

  • Runs inside a Kubernetes cluster.
  • Containerized using Docker.
  • Served using NGINX.
  • Accessible through a Kubernetes Service.
  • Supports rolling deployment updates.
  • Designed for horizontal scaling.
  • Used for Generative AI and RAG demonstrations.

Training Objectives

This application serves as the foundation for the remaining training modules. Students will first deploy the application on Kubernetes, then build AI capabilities including Tool Calling, Retrieval Augmented Generation (RAG), Knowledge Bases, and AI Agents using Amazon Bedrock.
