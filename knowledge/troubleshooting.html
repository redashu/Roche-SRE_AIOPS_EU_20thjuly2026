Kubernetes Troubleshooting Guide

This guide provides common Kubernetes issues, their possible causes, investigation steps, and recommended resolutions.

1. CrashLoopBackOff

Description

The container starts successfully but exits repeatedly. Kubernetes keeps restarting the container with an increasing delay between attempts.

Possible Causes

  • Application startup failure
  • Invalid configuration
  • Missing Secret or ConfigMap
  • Database connection failure
  • Failed liveness probe
  • Out Of Memory (OOMKilled)

Investigation

kubectl get pods

kubectl describe pod POD_NAME

kubectl logs POD_NAME

kubectl logs POD_NAME --previous

Resolution

  • Review application logs.
  • Validate configuration.
  • Check Secrets and ConfigMaps.
  • Verify dependent services.
  • Fix application startup errors.

2. ImagePullBackOff

Description

Kubernetes cannot download the container image from the registry.

Possible Causes

  • Incorrect image name
  • Incorrect image tag
  • Private registry authentication failure
  • Container registry unavailable

Investigation

kubectl describe pod POD_NAME

Resolution

  • Verify image name.
  • Verify image tag.
  • Configure imagePullSecrets.
  • Check registry connectivity.

3. Pending Pod

Description

The Pod has been created but has not yet been scheduled onto a node.

Possible Causes

  • Insufficient CPU
  • Insufficient Memory
  • Node Selector mismatch
  • Taints and Tolerations
  • Persistent Volume unavailable

Investigation

kubectl describe pod POD_NAME

kubectl get nodes

Resolution

  • Add cluster resources.
  • Reduce resource requests.
  • Check scheduling constraints.

4. OOMKilled

Description

The container exceeded its configured memory limit and was terminated by the operating system.

Possible Causes

  • Memory leak
  • Memory limit too low
  • Unexpected workload spike

Investigation

kubectl describe pod POD_NAME

kubectl top pod

Resolution

  • Increase memory limits.
  • Optimize application memory usage.
  • Monitor memory consumption.

5. Service Not Accessible

Description

The application is running but cannot be reached through the Kubernetes Service.

Possible Causes

  • Incorrect selector
  • TargetPort mismatch
  • Application not listening
  • Network Policy restriction

Investigation

kubectl get svc

kubectl describe svc SERVICE_NAME

kubectl get endpoints

Resolution

  • Verify labels and selectors.
  • Check target port.
  • Verify application port.

6. Pod Restarting Frequently

Investigation

kubectl get pods

kubectl describe pod POD_NAME

kubectl logs POD_NAME --previous

Possible Causes

  • Application crashes
  • Failed health checks
  • OOMKilled
  • Configuration errors
