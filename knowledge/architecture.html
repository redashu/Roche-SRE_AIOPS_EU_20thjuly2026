Payment Portal Architecture

Overview

Payment Portal is deployed as a containerized application on a Kubernetes cluster. The application is managed by a Deployment object and exposed to users through a Kubernetes Service.

Application Components

Component Description
Browser User accesses the web application.
NodePort Service Exposes the application outside the Kubernetes cluster.
Deployment Maintains the desired number of running Pods and manages updates.
Pod Runs the NGINX container hosting the website.
NGINX Serves static HTML pages.

High Availability

The Deployment continuously monitors the application. If a Pod fails, Kubernetes automatically creates a replacement Pod to maintain the desired application state. Services provide a stable endpoint for clients even though Pods are ephemeral and may be recreated with different IP addresses. :contentReference[oaicite:0]{index=0}
