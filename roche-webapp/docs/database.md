# Database Documentation

## Overview

The ChatApp application uses MySQL as its relational database.

The database is responsible for:

* User authentication
* Chat session management
* Persistent conversation storage

Database Name

```text
chatapp
```

---

# Entity Relationship

```text
users
   │
   │ 1
   │
   │ N
chat_sessions
   │
   │ 1
   │
   │ N
chat_messages
```

---

# Table: users

Purpose

Stores application users.

Schema

| Column     | Type         | Description          |
| ---------- | ------------ | -------------------- |
| id         | INT          | Primary Key          |
| username   | VARCHAR(100) | Login username       |
| password   | VARCHAR(255) | User password        |
| fullname   | VARCHAR(100) | Full name            |
| email      | VARCHAR(150) | Email address        |
| role       | VARCHAR(50)  | User role            |
| created_at | TIMESTAMP    | Record creation time |

Example

```sql
SELECT * FROM users;
```

---

# Table: chat_sessions

Purpose

Stores chat sessions created by users.

Schema

| Column     | Type         | Description           |
| ---------- | ------------ | --------------------- |
| id         | INT          | Primary Key           |
| user_id    | INT          | Foreign Key to users  |
| title      | VARCHAR(255) | Chat title            |
| created_at | TIMESTAMP    | Session creation time |

Example

```sql
SELECT * FROM chat_sessions;
```

---

# Table: chat_messages

Purpose

Stores every message exchanged between the user and the AI assistant.

Schema

| Column     | Type        | Description                  |
| ---------- | ----------- | ---------------------------- |
| id         | INT         | Primary Key                  |
| session_id | INT         | Foreign Key to chat_sessions |
| role       | VARCHAR(20) | user / assistant             |
| message    | TEXT        | Chat message                 |
| created_at | TIMESTAMP   | Message creation time        |

Example

```sql
SELECT * FROM chat_messages;
```

---

# Relationships

```text
users.id
        │
        ▼
chat_sessions.user_id
        │
        ▼
chat_messages.session_id
```

---

# Login Query

The application validates users using:

```sql
SELECT *
FROM users
WHERE username=?
AND password=?;
```

---

# Load Previous Conversation

```sql
SELECT role,message
FROM chat_messages
WHERE session_id=?
ORDER BY id;
```

---

# Save User Message

```sql
INSERT INTO chat_messages
(session_id,role,message)
VALUES
(?,?,?);
```

---

# Create New Chat Session

```sql
INSERT INTO chat_sessions
(user_id,title)
VALUES
(?,?);
```

```bash

```

# Restore

```bash
mysql -u root -p chatapp < chatapp_schema.sql
```

# Index Recommendations

Recommended indexes for future scalability:

```sql
CREATE INDEX idx_username
ON users(username);

CREATE INDEX idx_user_sessions
ON chat_sessions(user_id);

CREATE INDEX idx_session_messages
ON chat_messages(session_id);
```
